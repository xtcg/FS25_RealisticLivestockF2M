# FEED-05：饲料界面文案与语言回退

2026-10-10，在`feat/feed-real-equivalent`现有实现上完成独立文案子项。它不依赖待校准的营养参数，使用已存在的`RLFeedInfoService`及其真实扣料计划。

## 已完成

- 49个新文本键，中英文完整；其余15种语言采用英文回退，避免缺键直接显示在界面上。
- 公牛饲料说明包含青草、干草、青贮、TMR和小麦/玉米补料，并说明新模式、断奶、建筑支持、粗料和换料条件。
- 原料行百分比明确为干物质份额；库存旁的外推月量明确为计划L/月。动物行同时表达现实DM日摄入和实际ME/计划ME覆盖率，不能将后者理解为已单独核算的维护覆盖率。
- 营养模式未启用、配置无效、动物/食槽未覆盖、普通栏幼犊等原因均有文本；蛋白、粗料、糖类、小麦限额、适应、缺料和摄入容量有不同提示。
- 新旧摘要中的未知状态值显示本地化“未知”，不会直接拼出缺失的i18n键。

中文使用游戏字库支持的表达：“粗料限制”表示有效纤维约束，“糖类限制”表示淀粉加糖的可发酵碳水约束，“容量上限”表示粗料容积限制。17种语言的新短标签加入既有格宽检查。

## 验证与剩余工作

`tests/test_feed_ui_text.lua`使用真实喂养模拟产生的原料库存、DM份额、月计划和个体账，以17种语言逐一验证界面服务：51/51。`test_ui_text.lua`为119/119，`test_feed.lua`为64/64，共234项相关检查通过；全部语言XML可解析，`git diff --check`通过。

本子项不代表完整FEED-05验收。还需核对日粮编辑GUI、建筑不支持状态、完整月历史显示、维护/生产覆盖细分、动态行和换栏刷新、客户端摘要与实机排版。工作树原有未提交修改保留；本轮未提交、推送或部署。
