# 0.2.0.0 — Farm to Market

- 新存档默认开启现实等效营养；猪、羊 v2 生长模型默认开启。牛生长、体况和犊牛养育继续开启。
- 整合种公畜采精、服务费、批次身份与血统、精液管取还、按物种计价及每月商人收购配额。
- 修正受胎年龄曲线的千分比换算；一次授精只执行一次受胎判定。
- 适配 FS25 1.25 动物列表，并加入手动去势确认、中英文玩家指南、零库存主饲料和牧草显示修复。
- 保留已实测的菜单按钮容量、描述与财务翻译兼容修复；启动时不再显示信息性弹窗。

## 安装和已有存档

下载 `FS25_RealisticLivestockRM.zip`，不解压放入 mods 文件夹，并核对 `SHA256SUMS`。此文件名保留精液罐和手持工具已验证的运行命名空间；项目名称仍为 Farm to Market。升级前备份存档，移除旧 `FS25_RealisticLivestockF2M.zip`，不要同时加载两个包。

已有存档保留已保存的营养模式，若原来为 Legacy，可在 RL 设置中改为 Real-equivalent。用户 `modSettings/FS25_RealisticLivestockRM/weightProfiles.xml` 等覆盖文件仍优先于包内默认配置，旧覆盖若明确关闭猪羊模型，需要自行调整。

## 适用边界和待修项目

- 怀孕／产后母猪以及未断奶仔猪所在栏舍保留旧饲喂规则；山羊和独立 MILKCOW 类型保留兼容门禁。
- 商人 v2 新活畜交易通道仍关闭；本版精液交易不依赖该通道。
- 猪棚食物列表漏显、手持工具底部通用说明和示意图仍待完善；本轮失败的 r7 说明补丁未纳入发布。
- 本轮游戏验证覆盖 Hof Bergmann 单机猪羊主流程；牛／马采精、多人及受胎成功后的妊娠分支不属于本轮验收范围。
