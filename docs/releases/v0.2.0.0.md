# v0.2.0.0

## 中文

### 更新内容

- 新存档默认开启现实等效营养，以及猪、羊 v2 生长模型；牛生长、体况和犊牛养育继续开启。
- 整合种公畜采精、服务费、精液批次身份与血统、精液管取还、按物种计价及每月商人收购配额。
- 修正受胎年龄曲线的千分比换算；一次授精只执行一次受胎判定。
- 适配 FS25 1.25 动物列表，加入手动去势确认和中英文玩家指南，修复零库存主饲料和牧草显示。
- 保留菜单按钮容量、描述和财务翻译兼容修复；启动时不再显示信息性弹窗。
- 安装包统一为 `FS25_RealisticLivestockF2M.zip`；修复精液罐、授精工具及血统查询中写死的 RM 命名空间，运行时名称跟随实际包名。

### 安装与设置

下载 `FS25_RealisticLivestockF2M.zip`，无需解压，放入 FS25 的 mods 文件夹，并核对 `SHA256SUMS`。更新时替换原有 F2M 包；如存在 `FS25_RealisticLivestockRM.zip`，请移除，避免同时加载两个包。

已有存档保留已保存的营养模式。若原来为 Legacy，可在 RL 设置中改为 Real-equivalent。配置目录为 `modSettings/FS25_RealisticLivestockF2M/`；其中 `weightProfiles.xml` 等用户覆盖文件优先于包内默认配置，若覆盖文件明确关闭猪羊模型，需要自行调整。

## English

### Changes

- New saves default to Real-equivalent nutrition with pig and sheep v2 growth enabled. Cattle growth, body condition and calf rearing remain enabled.
- Integrates sire semen collection, service fees, batch identity and pedigree, straw withdrawal and return, species-specific pricing, and monthly dealer purchase quotas.
- Corrects the per-mille conversion in the conception age curve and performs one conception roll per insemination.
- Supports the FS25 1.25 Animals page, adds manual castration confirmation and the Chinese/English player guide, and fixes the display of primary feed and grass with zero stock.
- Retains menu button capacity, description and finance translation compatibility fixes. Informational startup popups are removed.
- Standardizes the archive name as `FS25_RealisticLivestockF2M.zip`. Fixes hardcoded RM namespaces in dewars, insemination tools and pedigree lookup so runtime names follow the actual package name.

### Installation and settings

Download `FS25_RealisticLivestockF2M.zip`, place it in the FS25 mods folder without extracting it, and verify `SHA256SUMS`. Replace the existing F2M package when updating. If `FS25_RealisticLivestockRM.zip` is present, remove it to avoid loading both packages.

Existing saves retain their saved nutrition mode. If it is Legacy, you can select Real-equivalent in RL settings. Configuration files are stored in `modSettings/FS25_RealisticLivestockF2M/`. User overrides such as `weightProfiles.xml` take precedence over packaged defaults; adjust overrides that explicitly disable pig or sheep growth if you want to enable those models.
